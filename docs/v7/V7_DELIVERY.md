## 5. 六部旗舰的最大改进（具体实例，不是形容词）

每部给 2–3 个「原典场景 → 新现场选择 → 后续回响」。完整变量链与 82 条回响断言见 `CHOICE_AND_PAYOFF_LEDGER.md`。

### 太华试序 · 三年之约（465 拍 / 3 结局）

1. **失败之后的面子**：`th_hold → strain` 处，玩家二选一 —— `th_shield` 把手藏进袖里说下次再打过，或 `th_demonstrate` 拿护腕摆出双方脚位、把失败也讲全。两条都从 `honest` 分出，进入不同的 `shared` 阶段，**后面「要不要喝那口汤」的走向不同**。
2. **开场第 4 拍就有人说话**：`th_tease`「低声问她：胡桃好吃，还是改步好玩？」——开场 2–8 拍内就有即时表达，不需要玩家先读完旁白。
3. 正典结果（`dt_106`、`th_48` 等）**不因选择改写**；被改写的是玩家的伤、位置、证据与 NPC 态度。

### 龙门问刀（356 拍）

`lm_ask_use → lm_asked` 五问分叉：`lm_ask_left`（问四十岁左手换刀为何没从此每回都换）、`lm_ask_qinghe_friend`（先问一个武当道人为何还认得宋老的旧刀）、`lm_ask_qinghe_ninth`（问玄门九席第九为什么连贺老也不能直接比）—— 三问把「榜谱层级」从术语变成本人亲口解释的事，后续走 `lm_old_press_end` / `lm_old_ask_twenty` / `lm_old_try_words` / `lm_practice_slow` 四条不同的练法。

### 第十二席（393 拍）

「王爷用了十几年，等一个真实的姓名」——玩家是陪练/地方馆师，选择决定你陪他让不让这一场。跨 44/52/58 岁与退席以后。

### 青石五友 · 守一天（447 拍）

十七岁到九十二岁的许长安，五人旧约。`qs_*` 链把「守一天」的选择一路带到一生回响。

### 死人争榜（325 拍）

`dr_*` 链：66 个选择点，24 个场景，**本篇与芦花渡是美术缺口最重的两篇（`# cg:` 触发为 0）**。

### 山河璧 / 盗玉篇（322 + 320 拍）

两卷可顺序进入：**第一卷 `jade-thieves`（密库双贼）→ 第二卷 `jade`（十三文）**，各自独立存档前缀 `jianghu:chronicle:jade-thieves:v2:` 与 `jianghu:chronicle:jade:v2:`。

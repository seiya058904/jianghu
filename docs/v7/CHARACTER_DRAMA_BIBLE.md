## 3. 通用 NPC 原型的用法

委托 §7.1 要求「普通路人、官差、随从、船夫、接引弟子沿用通用 NPC 原型系统；但要避免同屏撞脸、避免少年用老翁模板」。实测：

- 14 种原型：`matureWoman / youth / monk / robedElder / elder / martialElder / martialAdult / porter / merchant / traveler / clerk / boatwoman` + 两组借用（`v5-borrowed` / `v6-borrowed`）。
- 每篇的目录显式区分「原典人物」与「**原典留白人物**」——例如 `jd_qiao`（阿荞 · 带孩子领粮的人 · 原典留白人物）、`ss_tang`（阿棠 · 金陵录剑门人 · 原典留白人物）、`sr_boatman`（阿汀 · 同行船夫 · 原典留白人物）、`qs_runner`（阿满 · 边军新卒 · **原典留白人物**）。
- 这一命名法让「哪些是补白人物」在数据层就可见，不靠文档事后声明。

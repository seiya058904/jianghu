## 0. 计数口径

委托 §3 明确定义：

- **A 级（有戏剧实质）** = 玩家在正式可玩篇章中经历**带行为、带选择、带因果**的真实事件。
- **B 级（配篇 / 资料 / 历史演出）** = 历史/论武/名录类，允许风格不同（见闻、访谈、人物谱系、独立短演出）。
- **统计达标 ≠ 照搬原文 70% 字符，也不允许捏造不属于原作的事件凑比率。**

`tests/library.test.ts` 第 3 条断言的正是这条口径：**22 组全部有承载作品，其中 ≥18 组落在「可直接游玩」的版本上**（`playable ≥ 18`），且每个可玩版本必须 ≥60 拍、≥2 个个人结局。

| 指标 | 实测 | 断言位置 |
|---|---|---|
| 原典组数 | 22 | `tests/library.test.ts` |
| 有承载作品 | **22 / 22** | 同上，逐组 `groups.includes('原典NN')` |
| 可直接游玩（A 级承载） | **21 / 22** | `playable.length >= 18` |
| 锁定解锁后才可读（B 级资料） | 3 个版本：`bamboo` / `north-notes` / `beyond-ranking` | 同上，`locked` 集合 |

> 「锁定」不是「没有内容」，而是**按阅读锁设计成读完后解锁**：`bamboo` 需读完《龙门问刀》一种归宿，`beyond-ranking` 需读完《玄门旧史》与《白石谷外》各一种归宿，`north-notes` 需读完《北枪》与《乾坤》各一种归宿。见 `src/chronicle-access.ts`。

## 1. 逐组矩阵

字段说明：
- **正典锁定 (CANON_LOCK)**：原作确定不变的事实。来源为各篇 `*-catalog.ts` 的 `fact`（见闻）条目与 `chronicleFacts`，均为可核对的原文事实声明。
- **可选行动 (PLAYER_AGENCY)**：玩家能改变的现场路径（态度/准备/现场代价/局部关系）。由选项数量与结局数体现。
- **台账实测**：拍 / 选项 / 结局 / 场景 / 出场人物。

# 美术复用优先规则

2026-10-15，用户补充要求：尽量少生成具有特殊表达含义、只能对应一段情节的画面；未来改剧情、改内容时，应尽可能继续使用已有素材。

后续素材生产和场景接入遵循：

- 先查已有资源、适用人物年龄和场景条件，再决定是否确有缺口。改对白、改选项、改事件顺序不构成重新生图的理由。
- 环境以地点与空间结构为主，尽量不画确定人物、剧情文字、独特事故或已发生的结局。对白、字幕、天气氛围与轻量演出分别组合。
- 人物以稳定身份、服装和常见情绪为主。平静、专注、轻松、担忧应可跨场景使用；避免让画像固定执行一句台词、指向某张情节文书或携带一次性关键物。
- 通用原型保持明确映射和不同面孔变体，不能借用重要人物的脸。复用不能牺牲年龄、伤势、职业和同屏区分。
- CG 只留少量确需整幅构图的高光，不为每个分支和每次剧情改写重新配图。已有插图在人物、年代、环境和动作都成立时可复用；不能为凑调用数量把不合剧情的画面塞入场景。
- 事件含义留给正文、可替换字幕、角色站位和镜头节奏，不烘焙进图像中的文字与标识。

本轮此前已发起的六张 CG 请求已返回输出，现有文件保留并逐张评估；收到补充后没有继续追加同类请求，后续不再沿用逐节点追加专用画面的生产方式。它们的登记和实际接入分开核实；生成成功不自动计入正式验收。

仍遵守原委托的数量下限；在最低限度的关键插图之外优先使用可组合的通用资源。若后续要求发生冲突，以用户这条较新的复用原则决定具体美术方案，不能以旧蓝图为由无限追加生图。

# V6 默认入口与旧存档保护

本轮把 `/`、`index.html` 及对应子目录首页切到真正的 V6《潮生有约》，沿用原 `tide-v6.html` 的剧本、章节、V2存档空间及离线包。旧 V6 地址仍可续读相同进度。选篇及纪事的主篇返回链接归到默认首页。

首页增加“旧版《潮生有约》与原存档”直达入口。V5使用冻结数据和原V1存档空间；原首页数据与冻结V5数据字节相同。没有将旧V5存档冒充V6导入，也没有改写原著、剧情或旧档。半步与旧阅读器保持独立。

离线包明确包含首页、index和保留的V6地址。下载时重新请求稳定地址的HTML，防止已缓存的旧首页继续加载V5；既有其他作品缓存保留。根与子目录均实际放入旧首页标记、移除主篇与冻结迁移JS块，再下载、清HTTP缓存并断网打开新页面验证。原始旧V6结局备份、当前V6继续和V5原字节均检查。

800×360封面原来会把档案链接挤出首屏，现只在矮横屏收紧文字、并列继续/重新启程按钮并省略介绍段。360、390、412、800、1366、1440、1920宽度检查了实际边界、命中和链接往返；新开与已有进度封面都另存截图。实际查看横屏与手机图后，又发现手机页脚与两行档案链接重叠，现把页脚移到链接上方并增加实际间距断言。

本轮没有生成或修改美术图片。继续执行用户的复用要求：普通环境与器物、人物稳定身份和常用神态优先；文本承载可修改的剧情含义。涉及年龄、身份、武器状态等必要区别时仍保留真实性，不为复用而错用画面。

验证日志与状态见 [本轮汇总](../evidence/v6/default-entry-summary.json)。全量168单测和最终构建通过；修正手机页脚后，默认首页、原档、结局、存档、断网及155张图片根/子目录字节与解码的29项浏览器复验全部通过。完整主篇9路与V5档案8路已全部从开始走到结局，17项通过；主篇逐拍对白与保存命令/世界状态一致，四处刷新继续，旧篇亦保留章节、CG及旧数据隔离检查。

最初日志保留：主题测试误写light、相对链接测试误判，以及800×360真实封面问题。修正后重新构建并实测；没有把初轮失败写成通过。图谱覆盖报告metadata_changed，以当前源码、实际运行和哈希补核。

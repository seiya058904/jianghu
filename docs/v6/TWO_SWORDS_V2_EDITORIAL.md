# 《旧本归还》V2：三轮内部文学编辑

2026-10-16。本轮完整读 origin、books、later 三个制作模块，按结构、人物、替代路线三个目的改稿。31条逐项前后文记录在 `docs/evidence/v6/two-swords-editorial-changes.json`；包含一次对改稿的职业适配修正，因此不是31处互不重叠的最终节拍。没有生成、编辑图片，复用现有书案CG、谢知白三态和场景。

这份记录是内部审改证据。真人阅读时间、外部趣味评价、缺少专属身份与剑术动作画面仍未通过，不把第一册进度扩成全部委托完成。

## 第一轮：时间与行动承诺

全篇顺序按三代核读：沈四十三岁救学徒→六年返门与十五变→七日后又议一年→辞门与剑庐→沈八十余去世、林六十出头立派→谢庭松三日来访、三百余合→约一百六十年前新录剑门人→雨课、火灾、原笔固定毁失→三个月后七车七箱归还、回赠新本→两种职业实习→三十年后议录→又二十年两式归鸿→各自常差。主角不能继承前两代的亲见记忆。程问山只在旧录叙述，不作为活人出场。

- `ss_rain_work_6` 与湿卷选项：旧稿说“课后再搬”，火灾当夜剑架却仍未移，没有交代失约。现明确今日只做一项、另一项排明早；阿棠约定也改为明早。移架者当日清路，核湿卷者仍有可知的窄廊代价。
- `ss_afterwards_1`：旧稿提前返程后又询问同伴多留一日，冲淡前选项。现只是请顺路门人带信，先问原行程；门人只肯带信，半箱谱仍由主角背。没有追加无选择的延误。
- 保留固定两册亲批无完整副本的损失、抄本归还而原笔不能复活、南岳不是纵火者、两派最终仍为两家。普通录剑人不参与更改祖师时代的胜负。

## 第三轮：替代路线与延迟回响

- `ss_letter_plain`：先寄信者在 cottage 遇到漏写屋漏；直接回者才知道师弟昨日已下山等，自己去找。不是两个选项都无事发生。
- `ss_lesson`：亲试后记的课堂法，在 years_later 留有汗渍和具体露门记忆；原新并排法则在处理多人争论时发现两页不够，需另添页。两个职业都能读到自己的教学选择。
- `ss_kept_question`：整段保留者在 guihong 被年轻门人带来请两老看；分册者须调附册，剑会第三日才送到。没有把正文附一句去处当成所有借者必定会取附册。
- 核过移架×救人/救稿：只有未移架且另取课稿的组合导致阿棠三个月烫伤代笔；救人和清路分支不凭空加这伤。三个月后能试剑，五十年后的尾声不误写终身失能。
- 随赠书车与留楼：实际教师、实习、三十年后的来信或亲见、七十岁课务或借录、最后职业均不同。末次守约用信上值日时辰，适配两种职业；付代差者仍真少束脩。
- 三十年后阿棠只通过来信与回忆出现，不让年轻画像继续站在七十岁的现场；她的专属适龄画像仍缺，不能据此称年龄美术完成。

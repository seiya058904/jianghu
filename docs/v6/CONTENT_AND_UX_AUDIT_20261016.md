## 二、"还能看到旧稿"的确切来源

**位置**：游戏内 **"选一段江湖"面板**（`src/player.ts:210-212` 的 `showLibrary()`）。你把它说成"选片"，就是它。

面板由 `chronicleWorks` 数组（`src/chronicle-catalog.ts:215`）平铺渲染，**共 38 条作品入口**，其中 **18 条标题直接写着"旧稿"或"第二版旧稿"**：

```
枯河谷 · 旧稿 / 枯河谷 · 第二版旧稿
青石五友 · 旧稿 / 青石五友 · 第二版旧稿
太华试序 · 旧稿 / 太华试序 · 第二版旧稿
龙门秋会 · 旧稿 / 龙门问刀 · 第二版旧稿
第十二席 · 旧稿 / 第十二席 · 第二版旧稿
北枪与乾坤 · 三师一枪旧稿 / · 不会算账旧稿
山河璧 · 十三文旧稿 / · 密库双贼旧稿
海路两世 · 中原以外 · 旧稿 / · 归潮岛 · 旧稿
一剑两脉 · 旧本归还旧稿 / · 门外七问旧稿
```

面板底部另有固定一节 **"旧篇与原存档"**：`潮生有约 · v5 原版`、`半步之约`、`渡口无碑`。

**为什么会有**：这些是历史上的冻结版本（每个作品迭代过 1–3 版），保留是为了**让旧存档还能打开**、让玩家回看旧版演出。**设计上是有意的**。

**为什么会困惑**：它们和当前版**并排平铺、同一字号、无分组、无"推荐从这部开始"的引导**，而且标题里大大方方写着"旧稿"。新玩家看到 38 个入口、将近一半标着"旧稿"，第一反应必然是"这游戏怎么回事"。

**唯一需要澄清的**：`src/player.ts:262` 确认，首次游玩**不能用快进**（`skip` 只对已读内容生效）。旧稿入口没有因此次审核之外的任何问题，纯粹是信息架构问题。

## 四、"无聊"的量化原因

### 4.1 主篇结局段：连点 74 / 133 次

统计"连续没有出现任何选择、玩家只能一路点继续"的最长段落：

| 剧本 | 最长段 | 起点 | 占全篇 | ≥25 拍的长段累计 |
|---|---|---|---|---|
| `campaign-v6.ink`（主篇 v6） | **74 拍** | 行 1357 | 6% | 4 处共 179 拍（14%） |
| `campaign.ink`（主篇 v5） | **133 拍** | 行 1299 | 13% | 2 处共 162 拍（16%） |

定位到具体内容后确认：**这两段都发生在结局收束**（从"你留在青蒲渡…"一路铺陈到"全篇完"）。玩家做完最后一个选择，就要坐着连点 74（v5 是 133）次"继续"才能看完结局。

而 `src/player.ts:262` 确认**首次游玩不能快进**：

```
快进只经过已读内容。   // 未读过 → 提示并拒绝
```

所以第一次通关只能硬点，或手动开"自动播放"。

> 第二份委托文档原文：「**严禁将几千字原著逐段塞进固定对白框，令玩家一直按"继续"。**」

这就是体感"无聊"的第一来源。

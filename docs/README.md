## 九、阅读本目录的注意事项

1. **文档是叠加式迭代的**，历史段与最新段会同时存在，通常**追加段为最新**。不要只看文件开头。
2. **`ACCEPTANCE_MATRIX.md` / `MAIN_EXPANSION_PROGRESS.md` 已有过期内容**，见根 [AGENTS.md](../AGENTS.md) §6。
3. **截图证据不随公开快照发布**（入库 1930 张 / 约 1.4 GiB），文档里的 `docs/evidence/**.png` 链接在公开仓库中打不开；1062 份文本证据完整。详见 [evidence/README.md](evidence/README.md)。
4. **文档中引用的裸提交 SHA 在公开仓库中不可解析**（公开快照为单次导入提交）。

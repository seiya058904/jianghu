# 原作事实与游戏原创边界

原文定位均为项目内 `宋世江湖.md`。这份矩阵只写本轮实际核过并使用的事实，不替未读旧史补结论。

|依据|确认的事实|游戏中的落实|
|---|---|---|
|江湖总叙，25 行|“如今”以最近一届洛阳龙虎风云会后为准；旧榜按事发年记|原创故事置于此后，不逐席展示未知现榜，不把旧榜人物叫来参赛|
|武途深浅，29–79 行|入化、返真极罕见；内席不能硬换外榜|年轻主角只争地方差事与有限目标，无升级数值、无登谱奖励|
|榜谱旧制，81–268 行|小榜、府榜、路榜有地域与分量差别|序章说明小会不授榜位，终局真胜也只记一次问手|
|天下门庭，270–312 行|六大、八宗与海外海天门有不同位置|苏晚澄、陆汀舟是原创外务/行走弟子，不冒充内席；裴雁秋明确与河东裴氏无亲缘|
|六门旧会·太华试序，2022–2251 行|六门会武为内部隐秘活动，外人不能普通购票进入|青蒲会为原创公开地方小会；明确不称六门会武|
|玄门客过河中，1852–1900 行|一个局部拆法并不使晚辈跳过名家积累|用承重脚、场地与兵器观察改变有限目标；抢中线会付出伤势|
|海天门旧事·归潮岛，7424–7786 行|掌船、识水、救人、治事是实际职责；九席并非纯武力榜|借鉴职责设计，不假称主角获海天门传承。老舵师只是本地熟手|
|金陵南岳旧史·一剑两脉，11850 起、末段至13919|同源而独立，两种传承都有成立处|原创两位弟子争场地、留后手与改步的适用条件；不代替原文祖师定输赢|
|洞庭旧事·照水刀梁照水，34836–35057 行|榜次对应旧年；成长漫长，换场地影响胜负，冲动后还要有人善后|各路线的药、破网、赔船和雇工账在后日兑现；不重复梁照水的人生|
|太玄旧录·宁无极所评天下十人，35058 至末|私人旧录不是历代公榜，也非按年更新|游戏不把该旧录做成当代可攻略或可挑战名单|

新增设定：青蒲渡为未钉死府州坐标的地方河镇；水陆小会是护渡用工与年轻人试艺并行的民间活动。药车、船户、木匠、米行等生活结构受原文的行商、漕舟、门馆背景启发。所有具体事故、关系、胜负、结局均属原创。

未完成：上古、昆仑、许长安、江汉、山河璧、王府及太极/北地等长篇的全文细读和逐人物时代矩阵。它们在结构索引中有出处，但未被作为本篇的已核史实。该项仍是 v5 委托的明确未完成项。

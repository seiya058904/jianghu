# V6 编剧硬约束

事实来源：原文逐段审读见 CANON_MASTER_INDEX / V6_READING_NOTES；此文件为写作和回归检查输入，不能替代正文证据。

1. 口传十杰/五虎不是正式小榜；小、府、路先看榜级/地域/历史，再谈数字。路不一定对应行政路，每个府榜不必有上级路榜。
2. 地方现榜仅最高一层；升府撤小、升路撤府、升南北撤地方，旧录不删。南北可兼总谱。总谱百岁退，南北不受此死线，梁97退是活动少。
3. 榜不是擂台阶梯、善恶奖状、古今总强度；长期活动/战绩/对手/公平条件/认负决定可记程度。伤中胜仍胜但另注伤，不能用一次胜自动换席。
4. 内席衡职责/传承/辈分/武学，不是第几强；周望海较沈更适任、张无垢非前20仍九席、孟守川不能投徒弟路席票是可玩制度实例。
5. 普通人几十年开馆/地方名望才有望正式小榜，青年核心六门冠军仍远未入化。司马43入化68返真/陆玄都37入化45返真属于明确异数，不可当升级曲线。
6. 入化/返真不作玩家公开等级或NPC自报层数。总谱前三十五已入化或更高，第三十六韩世雄门前异数；不反推入化必占总谱/任何场必胜。清和与秦的一场按原文胜负记，不擅自给清和加境界。
7. 六大靠代代接续与榜外旧宿，八家返真可断仍不立降；海天与六大并论而不列中原六/八。最高不是掌门必然。
8. 公开洛阳与闭门六门必须分。六门青序45限、正序45以上已返真出序、当届青60正28，八家和海天无正式席。
9. 青序霍/明/谢/司马承一/陆青珩/沈照微；正序陆栖真/季闻鹤/慧觉/张玄岳/法舟/司马沉岳；门分18/17/14/8/5/1均锁定。霍问张6手止；玩家不能把十手约改成撑足十手。
10. 孟归藏不是陆归藏；张玄岳/玄度/玄衡不同代不同人；太极司马天岳与北地秦天岳不同门人；荣王赵承晏与靖王赵允和不同人；天都/天海/海天不同门。
11. 蓬莱北岛群、西海旧称远地需经蓬莱、东极归潮南深海分开。船/潮/礁/桨/救溺技能影响水战，岸上强弱不能直接搬海上。
12. 死亡重残长期存在。四友/许/江十七/空劫等不得无标识救活。谢藏锋失踪后至少11年仍活，不能把推死日当真死日；祁/天外仙未知生死不能编确证。
13. 山河璧无增功/疗伤/延寿/武学。柳观河从自己的积累借图思考，不是玉授武；九库本粮药军械/转运非神功宝库，真璧后来已碎。
14. 武不玄幻：距离/落步/重心/呼吸/先后/退路/经验；返真也不能硬抗山塌/军阵箭雨，护人/守时间比杀赢有意义。神异传闻必须标来源与不确定。
15. 玩家改变现场态度、准备、同伴小人物命运和未锁定旁支；历史胜负/创派结果锁定。默认忠实改编或正典补白，另史若制作须单独显式标，不混正式正史。
16. 所知按来源：亲见、可靠当事人、旧录、传闻分别记；竹院无青年，不给当前主角全知NPC私谈。角色回响不能记住未发生的路线。

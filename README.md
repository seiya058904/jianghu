> **Not everyone who enters the martial world becomes a legend.**
>
> You might be a substitute disciple at a gathering of six schools, a young attendant watching masters settle an old dispute, a prince who wants a truly fair match, or an ordinary person trying to keep old friends together.
>
> The established victories, losses, lives, and deaths of this world matter. Your choices do not erase its history. They determine what you notice, whom you trust, how you respond, and what your part of the story becomes.

## 🎮 How to Read and Play

- **Advance dialogue** by clicking the stage or using Enter / Space. When text is still appearing, the first click completes the current line.
- **Choose your own replies.** Autoplay and skipping previously read text do not automatically make important dialogue decisions.
- **Use the reading settings** to switch between paper and night themes, 18 / 20 / 22 / 24 text sizes, text speeds, and reduced motion. Use Tab to navigate controls and Escape to close panels.
- **Save at your pace.** The game auto-saves each line and offers three manual slots, a previous-session recovery feature, and JSON export/import.

> [!IMPORTANT]
> **Your saves are local, not cloud-synchronized.** Different browsers, devices, profiles, and site origins do not automatically share progress. Export a backup before clearing browser data. A story must be downloaded and cached before it can be opened offline for the first time.

## 📋 Status and Verification

The library is playable, but the historical independent acceptance was **not complete across every criterion**. Its final public audit recorded a partial performance assessment (F18) and a blocked author-history size target (F24); a later note records that the separately adopted daily-use directory met its size target without changing the historical author's archive result. Human reading and timing, physical Android devices, Safari, Firefox, and screen readers were not verified in that audit. See the dated [acceptance record](docs/audits/independent-final/FINAL_ACCEPTANCE.md) for the evidence and boundaries. These results apply to the audited revisions, not automatically to the current `main`.

## 🚀 Play or Run Locally

### 🌐 Play in Your Browser

**[Open the Jianghu Story Library →](https://seiya058904.github.io/jianghu/)**

The hosted edition is published through GitHub Pages. No desktop client is required. The narrative and user interface are written in Chinese; this README is provided in English for repository visitors.

### 💻 Run from Source

Requires **Node.js 24** and npm. From the repository root:

~~~bash
npm ci
npm run build
npm start
~~~

Open **http://127.0.0.1:4173/**.

The build compiles authored stories into runtime data, checks TypeScript, creates the Vite site, and generates its offline resource manifest.

<details>
<summary><strong>Development, verification, and content audits</strong></summary>

~~~bash
npm run dev                 # Vite development server
npm test                    # Story, runtime, save, and contract tests
npm run test:editorial      # Editorial draft checks
npx playwright install chromium
npm run test:e2e            # Browser interaction and offline tests
npm run audit:v7            # Story pacing and coverage analysis
npm run audit:independent   # Runtime and art audits (Python + Pillow for images)
~~~

**TypeScript · Vite · Ink / inkjs · Playwright**

Stories are authored and compiled ahead of time. The game does not depend on an online text-generation model for its narrative.

The current `main` branch uses regular Git development and GitHub Actions workflows for [verification](https://github.com/seiya058904/jianghu/actions/workflows/verify.yml) and [Pages deployment](https://github.com/seiya058904/jianghu/actions/workflows/deploy-pages.yml).

## 📜 Canon and Usage Rights

Jianghu adapts an original fictional canon with established characters, chronology, schools, rankings, and major outcomes. Contributions must preserve those facts unless the author explicitly revises the source material. The game's branching decisions are designed to change **participation and perspective**, not to erase canonical history.

This repository does **not** include a blanket open-source license. Public availability does not automatically grant permission to reproduce or redistribute its writing, character art, or source code. Consult the repository documentation for additional provenance and engineering constraints.
